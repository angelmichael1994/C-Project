# C Programming Projects

This repository contains C programming projects created to practice and demonstrate fundamental C programming concepts.

## Projects

### 1. Student Performance Analysis

A C program that manages student details, processes subject marks, and determines student performance and results.

*Concepts:* Structures, arrays, functions, loops, conditional statements, and macros.

### 2. Bus Reservation System

A console-based application for selecting bus types, viewing seats, booking seats, and cancelling reservations.

*Concepts:* Structures, enums, 2D arrays, pointers, pointer arithmetic, functions, strings, loops, and jump statements.

## Technologies

- C Programming
- GCC Compiler
- Git & GitHub

## Purpose

These projects demonstrate practical implementation of C programming concepts through simple console-based applications.
